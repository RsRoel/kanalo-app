# Kanalo — downloads and site

Public landing page, privacy policy and release downloads for **Kanalo**, an
Android TV / Fire TV player for your own M3U or Xtream Codes playlist.

- Site: https://rsroel.github.io/kanalo-app/
- Downloads: https://github.com/RsRoel/kanalo-app/releases
- Privacy: https://rsroel.github.io/kanalo-app/privacy.html

The app source lives in a separate repository. This one holds only what needs to
be publicly reachable: the page, the policy, `llms.txt`, and the signed APKs.

Static HTML on purpose — every competitor in this category is client-side
rendered and therefore invisible to search and AI crawlers.
